# Support

- **How-to questions:** use GitHub Discussions (if enabled) or open an issue labeled `question`.
- **Bugs:** use the issue template; include version, operating system, Python version, reproduction steps, and the error message with tokens, server addresses, library names, and personal information removed.
- **Security problems:** follow [SECURITY.md](SECURITY.md); do not post publicly.
- **Provider metadata disputes:** verify the source record and image licensing before opening an issue. The application cannot guarantee third-party identity matches.

This is a community project. No guaranteed uptime, response time, or enterprise support is offered. For Plex server issues unrelated to Cast Explorer, see [Plex Support](https://support.plex.tv/).
