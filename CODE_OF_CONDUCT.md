# Code of conduct

Be respectful and constructive in issues, discussions, code reviews, and other project spaces. Critique ideas and code, not people. Harassment, discrimination, threats, doxxing, sexually harassing remarks, and sharing private information are not acceptable.

Maintainers may edit or remove harmful content, close discussions, and restrict participants to keep the project useful and safe. For suspected violations, use GitHub's content reporting tools or contact the repository owner privately through an agreed channel. **Do not post personal details in a public issue.**

The project may index sensitive or adult-oriented library titles, but public contributions and bug reports should use neutral, synthetic examples rather than real personal viewing histories or explicit imagery.
