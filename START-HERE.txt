Plex Cast Explorer v0.4.7-beta: Windows Installer Build Kit
============================================================

Windows users building the public installer:
  1. Extract this ZIP to a new folder (outside Program Files).
  2. Double-click BUILD-INSTALLER.cmd.
  3. The script builds the Python EXE, verifies WinSW and compiles
     a full-featured Windows Setup wizard using Inno Setup 6.
  4. Find PlexCastExplorer-Setup-0.4.7-beta-win-x64.exe in output\.
  5. Back up C:\ProgramData\PlexCastExplorer and run the wizard.
     Existing service installs are upgraded in place; no migration.

Features: install directory, port, private-LAN firewall rule,
TMDB opt-in, VPN-restricted remote admin, stable/beta update channel,
Start Menu shortcuts and Windows uninstaller.

After installation use the Start Menu shortcuts to:
  - Set Gallery Password (required for fresh installations)
  - Set Remote Admin Password (only when VPN allowlist enabled)
  - Check for Updates (manual, checksum-verified when published)

IMPORTANT:
  - This ZIP contains source and installer-builder scripts, not a
    precompiled Windows installer. Build the actual EXE on Windows.
  - Do not uninstall your already-working service before upgrading.
  - The service uses HTTP. Never forward the service port from your router.
  - Running code on GitHub (Actions, builds, CI) is NOT required.
  - TMDB opt-in does not waive TMDB's use restrictions/attribution rules.

Read docs\WINDOWS_INSTALLER.md for more information.
